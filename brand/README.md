# Brand

Single source: `brand/icon.svg`. Regenerate all derived assets in `public/` with `pnpm icons`.

| Token | Hex | Use |
|---|---|---|
| Ink | `#0f1115` | Background, theme color, manifest background |
| Ball orange | `#ff7a1a` | Ball in the mark |
| Hand teal | `#5eead4` | Hand arc motif |

Style: flat, no text, no shadows. Maskable icon keeps the art inside the central 70% safe zone.
